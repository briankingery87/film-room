The Film Room is the analytics side of the CFB Atlas, a college football data and mapping project covering all 666 NCAA programs across FBS, FCS, Division II and Division III. Built and maintained by Brian Kingery. One HTML file, no server, no API key - it reads the published services live on every load.

Data
CFB Atlas hosted feature services, ArcGIS Online. Source data: College Football Data (CFBD), the US Census via Esri Living Atlas, and the brand-weighted gravity model documented in Modeling College Football Fan Territory.
Fan territory is a model estimate, not survey data. Every derived number on this page is computed in your browser from those services and the working is shown next to it.
Built with
Nothing. No chart library, no framework, no map engine - every plot here is inline SVG this file writes itself.
